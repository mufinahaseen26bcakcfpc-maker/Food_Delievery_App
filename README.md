# Food Delivery Mobile App – README

## 📱 Project Overview

This project is a modern **Food Delivery Mobile Application UI/UX Design** created in **Figma**. The application provides a smooth and user-friendly experience for browsing restaurants, ordering food, selecting delivery addresses, making payments, and tracking orders.

The design follows a **warm brown and cream color palette** with rounded cards, high-quality food images, and a clean layout to create an attractive and premium food ordering experience.

---

# Design Theme

* **Primary Color:** Brown (#5A2D0C)
* **Secondary Color:** Cream / Beige
* **Accent Color:** Golden Yellow
* **Style:** Modern Minimal UI
* **Platform:** Mobile (iPhone)
* **Design Tool:** Figma
